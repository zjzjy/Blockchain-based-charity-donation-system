# Mercy Remix MVP - 慈善捐赠追踪与自动发放系统

## 项目简介
这是一个基于以太坊的慈善捐赠追踪与自动发放系统。该系统允许创建慈善项目、接受捐赠、跟踪项目进度，并通过智能合约自动管理资金发放。系统特别强调透明度和民主决策，要求所有捐赠者参与项目里程碑的投票决策。

## 主要功能
1. 捐赠者管理
   - 捐赠者注册
   - 捐赠者状态更新
   - 捐赠者信息查询

2. 项目管理
   - 创建慈善项目
   - 设置项目里程碑
   - 更新项目状态
   - 查询项目信息

3. 捐赠功能
   - 向项目进行捐赠
   - 查看捐赠记录
   - 统计捐赠信息

4. 里程碑投票系统
   - 捐赠者对里程碑完成情况投票
   - 查看投票状态
   - 自动资金发放（需全体捐赠者同意）


## 开发环境

- 开发工具: Remix IDE
- 测试网络: Remix JavaScript VM (London)

### 完整流程自动化执行说明

在此流程中，以下事件会自动触发，无需手动调用：

1. **项目资金状态自动更新**：
   - 当捐赠总额达到项目目标时，项目状态自动从REGISTERED变为STARTED
   
2. **里程碑资金自动释放**：
   - 当某个里程碑获得所有捐赠者同意投票后，该里程碑对应的资金会被自动释放
   - 系统会触发`FundingReleased`事件
   
3. **项目状态自动进展**：
   - 第一个里程碑完成并获得投票：项目状态更新为STARTED（如果还不是）
   - 中间里程碑完成并获得投票：项目状态更新为IN_PROGRESS
   - 所有里程碑完成并获得投票：项目状态自动更新为COMPLETED
   
4. **事件监控**：
   - 整个过程中可在Remix的"Logs"面板观察所有触发的事件
