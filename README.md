# 区块链慈善捐赠跟踪与自动拨款系统

![License](https://img.shields.io/badge/license-ISC-blue.svg)

## 项目概述

基于区块链技术的慈善捐赠管理系统，实现透明可追溯的捐赠流程与自动化资金拨款。通过区块链不可篡改特性与智能合约，确保慈善项目全流程公开透明，建立捐赠者与慈善机构间的信任。

## 版本实现

- **mercy** - 基于Hyperledger Fabric的企业级实现
- **mercy-remix-MVP** - 基于以太坊的最小可行产品(MVP)

## 核心功能

- **透明度追踪** - 区块链记录全部交易，确保不可篡改
- **里程碑管理** - 项目资金分阶段自动释放
- **多方共识验证** - 捐赠者参与资金释放决策
- **自动化执行** - 智能合约触发资金拨款

## 技术栈

### Hyperledger Fabric版本
- 区块链底层：Hyperledger Fabric
- 智能合约：Chaincode (Go)
- API层：Node.js RESTful服务

### 以太坊版本
- 区块链底层：以太坊
- 智能合约：Solidity
- 开发环境：Remix IDE

## 业务流程

1. **项目定义** - 创建项目与里程碑计划
2. **资金筹集** - 接收捐赠并锁定资金
3. **进度验证** - 项目所有者提交里程碑完成证明
4. **多方共识** - 捐赠者投票确认里程碑完成
5. **自动执行** - 达成共识后智能合约自动释放资金

## 部署指南

### Hyperledger Fabric版本

```bash
# 克隆代码
git clone https://github.com/username/repo.git
cd mercy/mercy

# 安装依赖
npm install

# 部署网络
./scripts/deployNetwork.sh

# 部署智能合约
./scripts/deployChaincode.sh
```

### 以太坊版本

```bash
# 编译合约
npx hardhat compile

# 部署合约
npx hardhat run scripts/deploy.js --network <network_name>
```
