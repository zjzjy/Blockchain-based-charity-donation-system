# 慈善捐赠管理系统工作流程

## 1. 系统初始化

### 1.1 参与者注册
1. **项目所有者注册**
   - 提供组织信息（名称、注册号、联系方式等）
   - 系统验证组织资质
   - 分配唯一标识符（ownerId）
   - 设置合规状态为 `VERIFIED`

2. **审计员注册**
   - 提供个人信息（姓名、组织、认证信息等）
   - 系统验证审计资质
   - 分配唯一标识符（auditorId）

3. **捐赠者注册**
   - 提供个人信息（姓名、邮箱、钱包地址等）
   - 选择感兴趣的捐赠类别
   - 分配唯一标识符（donorId）
   - 设置初始状态为 `ACTIVE`

## 2. 项目生命周期

### 2.1 项目注册与启动
1. **项目注册**
   - 项目所有者提交项目信息
     - 基本信息（名称、描述、时间范围）
     - 资金需求
     - 里程碑计划
     - 资金里程碑
     - 团队信息
   - 系统创建项目，状态设为 `REGISTERED`

2. **项目合规验证**
   - 审计员审核项目合规性
   - 验证项目资质和文件
   - 更新项目合规状态为 `VERIFIED` 或 `UNVERIFIED`
   - 记录审计报告哈希

3. **项目启动**
   - 审计员验证项目合规性后
   - 系统检查初始资金是否达到50%
   - 更新项目状态为 `LAUNCHED`

### 2.2 捐赠流程
1. **捐赠发起**
   - 捐赠者选择目标项目
   - 输入捐赠金额
   - 系统验证：
     - 捐赠者状态是否为 `ACTIVE`
     - 项目状态是否允许接受捐赠
     - 捐赠金额是否超过项目剩余需求

2. **捐赠处理**
   - 系统记录捐赠交易
   - 更新项目已分配资金
   - 更新捐赠者累计捐赠金额
   - 触发 `DonationMade` 事件

3. **资金状态更新**
   - 系统自动检查资金状态：
     - 达到100%：状态更新为 `COMPLETED`
     - 达到80%：状态更新为 `PARTIAL`，项目状态可能更新为 `IN_PROGRESS`

### 2.3 项目执行与监控
1. **里程碑管理**
   - 项目所有者更新里程碑进度
     - 标记里程碑完成
     - 提交验证文档
   - 审计员验证里程碑
     - 审核完成情况
     - 确认验证文档
     - 更新验证状态

2. **资金释放**
   - 审计员根据里程碑完成情况释放资金
   - 系统验证：
     - 项目状态是否允许释放
     - 里程碑是否完成并验证
     - 释放金额是否合法
   - 更新资金里程碑状态
   - 记录已释放资金总额

3. **项目状态更新**
   - 审计员提议状态更新
   - 捐赠者审批状态更新
   - 系统验证状态转换合法性
   - 更新项目状态

### 2.4 项目异常处理
1. **项目冻结**
   - 触发条件：
     - 审计员发现合规问题
     - 捐赠者提出质疑
   - 系统操作：
     - 记录冻结前状态
     - 更新项目状态为 `FROZEN`
     - 更新资金状态为 `FROZEN`
     - 记录冻结原因和发起人

2. **项目解冻**
   - 审计员和捐赠者共同确认
   - 系统操作：
     - 验证解冻条件
     - 恢复到冻结前状态
     - 更新资金状态
     - 记录解冻原因和时间

3. **项目取消**
   - 触发条件：
     - 严重违规
     - 无法继续执行
   - 系统操作：
     - 更新项目状态为 `CANCELLED`
     - 更新资金状态为 `CANCELLED`
     - 处理剩余资金

```mermaid
    M --> N[捐款满100% Donor]
    N --> O[项目更新里程碑 ProjectOwner]

    项目完成
    Q --> R[更新项目状态 Auditor]

    T --> U[更新项目状态 Auditor]
    U --> V[项目完成]
```


## 流程说明

### 项目启动阶段
1. 注册项目
2. 审批项目合规性
3. 募集50%资金
4. 审批项目启动

### 项目执行阶段（第一阶段）
1. 更新项目里程碑
2. 审批里程碑完成情况
3. 更新项目状态
4. 发放30%资金

### 项目执行阶段（第二阶段）
1. 募集80%资金
2. 更新项目里程碑
3. 审批里程碑完成情况
4. 更新项目状态
5. 发放30%资金

### 项目完成阶段
1. 募集100%资金
2. 更新项目里程碑
3. 审批里程碑完成情况
4. 发放20%资金
5. 更新项目状态
6. 更新最终里程碑
7. 审批最终里程碑
8. 更新项目状态为完成
